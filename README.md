# คาบ · ตารางเรียน KU ฉบับนิสิต

https://ku-khab.vercel.app

เว็บดูตารางเรียนสำหรับนิสิต ม.เกษตรศาสตร์ วางรายวิชาจาก MyKU แล้วรู้ทันทีว่าคาบถัดไปคืออะไร

- ไม่ต้องใช้รหัสนนทรี ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้เท่านั้น
- ตารางทั้งสัปดาห์ / รายวัน, ธีม 11 แบบ, บันทึกเป็นรูป
- ไม่ใช่ระบบของมหาวิทยาลัย ตรวจสอบตารางจริงกับ MyKU เสมอ
